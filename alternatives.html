LitBuy Spreadsheet Decision Paths

Decision paths for keeping, rechecking, replacing, or deferring one LitBuy Spreadsheet row.

Decision paths

Choose a path by evidence quality and task fit

These paths are not a ranking of sources. They describe what to do with one review after comparing identity, selection, visible evidence, and observation time.

Compare on supported fields

Choose this path only when identity, selection, evidence, and date support the same conclusion. Record why no further check is needed.

Expected output: a dated comparison-criteria review note with the selected path and its evidence boundary.

Separate incomparable evidence

Choose this path when a limited change can be explained with visible evidence. Preserve both the old and new observation.

Expected output: a dated comparison-criteria review note with the selected path and its evidence boundary.

Request one missing criterion

Choose this path when the earlier record no longer describes the live source. State what was replaced and why.

Expected output: a dated comparison-criteria review note with the selected path and its evidence boundary.

Record no decision

Choose this path when a required field is missing, conflicting, gated, or unsafe to infer. Name the next check instead of forcing a conclusion.

Expected output: a dated comparison-criteria review note with the selected path and its evidence boundary.

Selection rule

Use the least assumptive path that still solves the task

Start with decision question, candidate rows or sources, comparable fields, observation dates, and exclusions. Select a path only when the record explains why that choice is supported. If two paths appear equally plausible, the missing distinction is itself an evidence gap.

Example: two rows appear similar but one lacks option identity; supported fields are compared while that dimension has no winner. In that situation, preserving uncertainty creates a more useful result than choosing the path that makes the row appear complete.

  • Prefer a reversible note when evidence is incomplete.
  • Keep earlier observations when a replacement is recorded.
  • Attach one next action and date to every deferred decision.

Boundary

Do not turn a path into a guarantee

If candidates do not share intent, option scope, or evidence date, do not collapse them into a single score.

A selected path documents the review process; it does not guarantee current inventory, price, quality, shipping, or policy outcomes. Those details remain controlled by the live source.

  • No unsupported score or best-choice claim.
  • No inference from a similar row or another brand.
  • No hidden overwrite of conflicting evidence.

Handoff

Record why the path was chosen

Finish with a criteria sheet defining one decision, evidence fields, exclusion rules, and the unresolved-result path. The note should show the scoped question, considered alternatives, accepted evidence, rejected evidence, and the next date.

A reviewer should be able to reopen the source and understand the decision without depending on private memory or an unexplained label.
